NEON SPEAKEASY - FIREWORKS: CLAUDE NOTES (2026-10-31)
How I checked: I could not listen, so each file was judged from a spectrogram plus a 10 ms level trace, an EBU R128
loudness measurement (ffmpeg ebur128, true peak 4x oversampled), and clipping tests on the ORIGINAL file: samples at full
scale, runs of identical samples near the peak, and "flat-top" runs (consecutive samples within 0.99 of the peak that
change by less than 0.05% of it per sample). Every delivered file passed: no flat run longer than 5 samples and no run
of identical peak samples. All numbers below are measured on the delivered files, which are byte-identical to the
originals. Times are seconds from the start of the file. "Rel" means dB relative to the file's loudest moment.
"First 50 ms at X rel" shows how abrupt the start is (below about -40 rel is a clean start).
