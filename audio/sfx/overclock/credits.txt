README-notes
- All files: MP3, 44.1 kHz, 192 kbps CBR. UI sounds are mono; 08, 15, 17 (and 17-b), 20, 21, 23 are stereo. Leading silence is trimmed to under 5 ms, true peak is at or below -1.4 dBTP, and nothing clips.
- Loudness tiers (max momentary LUFS): headline about -11 to -12 (17, 17-b, 21, 23); feedback about -13 to -15 (01, 02, 03, 06, 07, 08, 16, 18); secondary about -16 to -19 (11, 12, 13, 14, 15, 19, 20, 22); UI ticks -21 to -29 (04, 05, 09, 10). Mix music under these and do not normalise again.
- 03 combo: one source at 0 / +3 / +7 semitones (x2 / x3 / x5), all the same length (~0.44 s).
- 14 memory tones: one supersaw pluck (root C5, about 523 Hz) shifted 0,+2,+4,+7,+9,+12,+14,+16,+19 st = C5 D5 E5 G5 A5 C6 D6 E6 G6 (C-major pentatonic, so any order sounds consonant). Each is 0.80 s and loudness-matched. Tone 1 is the lowest.
- 20 hooves: exactly 2.500 s (110250 samples at 44.1 kHz), built to loop seamlessly with no fades at the ends. Use Web Audio: src.loop = true. For gapless looping on every browser, set src.loopStart = (index of the first non-zero sample) / sampleRate and src.loopEnd = loopStart + 2.5, which skips any MP3 encoder padding a decoder leaves in. An <audio loop> element will gap on Safari.
- iOS Safari: audio stays locked until a user gesture. Create or resume the AudioContext inside the first tap or click handler (ctx.resume()), then decodeAudioData every file once into AudioBuffers and play them with AudioBufferSourceNode for low latency. Avoid <audio> elements for SFX. Note: the iPhone silent switch mutes Web Audio by default, so include an in-game mute toggle.
- 07 321-go is one 1.68 s file (beeps at 0 / 0.35 / 0.70 s, GO at 1.05 s). If the UI counts down slower, play 05-tick-urgent per count instead and use 07 only for the quick version.
- Tile-place (10) and tick (04) are deliberately quiet and short because they repeat a lot. For rapid repeats, add slight random pitch (playbackRate 0.97-1.03).
